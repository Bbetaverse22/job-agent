# Writing Style Rules
- Plain, confident, concrete. No filler: passionate, results-driven, leverage (verb), utilize.
- Verb calibration: Built/designed = personally did; Led = owned outcome;
  Contributed = shared; Prototyped = experiments (never dressed up as production).
- CV bullets: verb + what + tech + outcome; metric only if verified; 1–2 lines.
- Cover letters: ≤250 words, 3 paragraphs (researched hook / one proof point /
  constraint-free close). No restating the CV. No exclamation marks.
- Behavioral answers: STAR, 100–150 words, first sentence answers the question.
